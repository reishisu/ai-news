8/22 2:18 JST ⚠ 仕様変更 Claude Code

2.1.239 で、そのプロキシを通る対象が広がりました。

CHANGELOG 2.1.239 の原文
Claude Code on the web: requests from Bash and other tools to non-API anthropic.com hosts (e.g. www, docs) now go through the session's network proxy, so your environment's allowed domains apply

これまで api.anthropic.com 以外の anthropic.com ホストは素通りしていました。今後は環境の許可ドメインの判定を受けます。許可リストに入っていなければ、昨日まで通っていた curl https://docs.anthropic.com/… が落ちます。

  • 影響するのはクラウドセッションだけ。手元の端末で動かしている Claude Code には関係ありません。原文も「Claude Code on the web」と限定しています。
  • 逆に言えば、環境のポリシーが効くようになったということ。許可ドメインを絞っている組織では、これまで判定を受けずに通っていた経路が塞がったことになります。
  • 今やること。Claude Code on the web で anthropic.com のドキュメントを取得する手順を持っているなら、その環境の許可ドメインに docs.anthropic.com などが入っているか確認する。入っていなければ追加する。手元で動かしているだけなら対応は不要。

CloudFrontがS3 Multi-Region Access PointをOACで保護できるようになった — Lambda@Edgeの自前署名が不要に

8/21 3:30 JST 新機能 CloudFront S3

用語を先に置きます。OAC（Origin Access Control）は、S3バケットへのアクセスを「指定したCloudFrontディストリビューション経由だけ」に絞る仕組みです。これが無いと、S3のURLを直接叩かれてCloudFrontを迂回されます。

S3 Multi-Region Access Point（MRAP）は、複数リージョンに複製したバケットを1つのエンドポイントでまとめる機能です。キャッシュミスのときに、一番近いリージョンから取ってきます。

これまで、この2つを組み合わせるには自分で署名を計算する必要がありました。

AWS What's New（2026年8月20日付）の原文
Previously, customers had to compute and forward their own Asymmetric Signature Version 4 (SigV4a) Authorization header using a custom Lambda@Edge Function. Now, CloudFront natively signs requests to S3 MRAP origins.

つまり、Lambda@Edgeで書いていた署名コードを外せるようになりました。SigV4a は複数リージョンにまたがる署名方式で、Lambda@Edge はCloudFrontのエッジで動く小さな関数です。

  • 使えない場所が1つある。「CloudFrontの中国リージョンを除き、世界中で利用可能」と原文にあります。追加料金は無いと明記されています。
  • 単一リージョン構成には関係がない。ap-northeast-1 のバケット1つをCloudFrontで配っているだけなら、MRAP自体を使っていないので今回の変更の対象外です。従来どおりの OAC が使えます。
  • これは前号の拾い直しです。公開は日本時間8月21日3:30で、前号（8/21）の対象期間内でしたが、そこでは「Web開発・インフラは動きなし」としていました。ここで訂正します。
  • 今やること。対応は不要。MRAPを使っていて、署名のためだけにLambda@Edgeを置いているなら、それを外せないか検討する。使っていなければ何もしなくてよい。

Claude Security のスキャンが Claude Mythos 5 で動くようになった — OSS向けに3,500万ドルのクレジット枠も

8/21 発表 新機能 セキュリティ

Claude Security は、リポジトリを走査して脆弱性を見つけ、修正案を出す機能です。8月21日付の公式ブログで、このスキャンが最上位モデル Claude Mythos 5 で動くようになったと発表されました。

Anthropic 公式ブログ（2026年8月21日）の原文
Starting today, Claude Security scans now run on Claude Mythos 5. Claude Security scans codebases for vulnerabilities and suggests patches for human review; it's currently in public beta for Claude Enterprise customers, and scans with Mythos 5 are billed as standard token usage under your existing plan, with no separate add-on.

対象は Claude Enterprise プランのpublic betaで、追加のアドオン契約は不要、通常のトークン利用として課金されます。

  • モデルそのものに触れるわけではない。スキャン結果は CWE分類・確信度・深刻度・修正案として返り、修正の実装は組織が Claude Code で使えるモデルで行う、と書かれています。「Mythosのスキャンが他の場面へのMythos利用を広げることはない」と明記されています。すべての修正は人のレビューと承認が必要です。
  • OSS向けに3,500万ドルのクレジット枠。Defender Advantage Fund（0xDAF）として、OSSの脆弱性修正・走査と修正の自動化・新しい手法の実験に取り組む組織へクレジットを提供する、とあります。
  • 今やること。対応は不要。Claude Enterprise を契約している組織のみ、管理コンソールから有効化できる。個人プランや Team プランには関係がない。OSSを運営していて資金が要るなら、この枠の存在を覚えておく。
