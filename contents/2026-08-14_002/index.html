Claude Codeの「自動モード」が本日からPro / Max / Teamの標準に — 承認ボタンを押す運用が終わる

8/14 ✓ 公式確認済 Claude Code Pro / Max / Team

Claude Code(ターミナル上でAnthropicのClaudeにファイル編集やコマンド実行まで任せる開発者向けツール)の自律実行モード「Auto Mode」が、8月14日から新規セッションの既定値になりました。ツール呼び出し(AIが自分でファイルを書き換えたりコマンドを実行したりする、一つ一つの操作)のたびに人が承認する方式から、分類器が審査して危険な操作だけを止める方式に変わります。

  • 分類器が止めるのは3系統だけ。「不可逆な操作」「破壊的な操作」「環境の外に向かう操作」が対象です。あらゆる危険を網羅的に審査するわけではありません。
  • 詰まったら勝手に手動へ戻る。ブロックが3回連続、またはセッション全体で20回に達すると、Claude Codeは手動承認モードにフォールバックします。
  • 分類器のトークン課金は8月7日付で廃止済み。公式ブログの公開日である8月7日に「effective today」でなくなりました。8月14日は既定化の日であって、課金廃止の日ではありません。
  • 「何も変わらない」とは限らない。自分で別の既定値を設定している人には、自動モードへ切り替えるか尋ねる確認が一度だけ出ます。完全に無変更なのは、ピン留めした既定値と、管理者がmanaged settingsで指定した場合だけです。Enterprise・API・各クラウド経由は当面オプトインのままです。

最近足された安全側の仕組み(分類器の審査対象そのものとは別)
公式ブログは「Making auto mode even safer」の章で、最近の追加として次の4つを挙げています。
  • ハード拒否。コードや秘密情報を外部へ送る操作は、要求されても決して承認しない区分に置かれています。設定でルールを追加できます。
  • データの取り扱いルール。git push やプルリクエストの宛先が公開か非公開か信頼済みかを、実行前に確認します。同じpushでも、届く先によって日常作業にも情報流出にもなるためです。
  • 破壊的なgit操作の前にgit statusを見る。git reset --hard のようにコミット前の作業を捨てうるコマンドの前に、リポジトリ(プログラムの保管庫)の現在の状態を分類器に渡します。
  • プロンプトインジェクションのスクリーニング。Webページやファイルに仕込まれた文章をAIが命令と誤読して従ってしまう攻撃を、API側のプローブが検知します。ただしブロックはしません。「injectionらしい」と判断した場合、結果を利用者に渡す前にClaudeの文脈へ警告を追加する、という挙動です。
第三者検証はある。ただし委託

人と分類器を比べた数字
1,053人の有料テスターを使った対照実験で、危険なコマンドを止められたのは人が13.6%、自動モードが89%だったとAnthropicは報告しています。分類器の見逃し率は、Apolloの攻撃セットに対して12%→7%に下がったとのこと。ただしこれは敵対的に作った合成攻撃に対する数字で、実トラフィックでの見逃し率ではないと明記されています。

Copilotの一部機能が8月18日で終了 — Deep Research・ポッドキャスト・グループチャット

8/13 ⚠ 報道ベース Copilot 8/18終了

個人向けCopilotアプリと法人向けMicrosoft 365 Copilotの統合にあわせ、伸び悩んだ機能が8月18日で終了します。使っている機能があるなら、それまでに移行先の確認が必要です。

  • Deep Researchは新規受付を停止。既存レポートの閲覧とWord形式へのエクスポートは引き続き可能です。
  • 後継はMicrosoft 365 Premiumの「Researcher」。加入者は同種のリサーチを継続できます。
  • グループチャットとCopilot Labsの実験機能も同日で止まります。Microsoftが挙げている狙いは「よりシンプルで一貫した体験(a simpler, more cohesive experience)」です。
  • 「Mico」は終了ではありません。公式FAQは「Copilot Voice のアニメーションキャラクターである Mico は Learn Live へ移る。Copilot の音声機能が無くなるわけではない」と明記しています。音声で話す機能はそのまま使えて、Micoがその場に出てこなくなるだけです。Learn Live では引き続きチューター役として動きます。
  • 移行中に他の機能も一時的に消えることがある、とMicrosoftは警告。単体のCopilotアプリが生成したファイルはOneDriveへ移されます。

重み(学習の成果である数値の塊。これを配れば手元で同じモデルを動かせます)が公開されました。注目は規模だけでなくライセンスで、他の多くのQwenモデルが使うApache 2.0ではなく、独自の「Qwen3.8-Max License」が付いています。

  • 「Qwen3.8-Max」とは別物です。公開されたのは Qwen3.8-2.4T-A95B。API提供のQwen3.8-Maxは、これに視覚入力・非thinkingモード・既定1Mコンテキスト・公式内蔵ツールを足した公式版だとモデルカードが明記しています。
  • 公開版はテキスト専用で、thinkingを切れません。すべての応答が <think>…</think> の推論から始まります。コンテキストはネイティブ262,144トークン、最大1,010,000トークンまで拡張可能。
  • 構成は92層・512エキスパートのMoE。MoE(全パラメータを毎回使わず、入力ごとに一部の「専門家」だけを動かす方式)なので、総2.4兆に対して1トークンあたり動くのは950億。うち10個がルーティングで選ばれ、1個は常時共有です。

Metaが「Muse Glimmer」を公開 — 民生用GPU1枚で、ネットにつながずエージェントが動く

8/10 ✓ 公式確認済 オープンウェイト Apache 2.0

300億パラメータの軽量モデルがApache 2.0(ほぼ制限なく商用利用できる代表的なライセンス)で公開されました。量子化(数値を粗くしてサイズを削る圧縮)で言語モデル本体を20GB未満に収め、GPUメモリ24GBまたは32GBの民生用GPU1枚で動く設計です。

  • できるのは日常的なエージェント作業。ローカルエージェント、関数呼び出し、ローカルでのコーディング、LLM-as-a-judge評価などをMetaは挙げています。
  • 今日使えるのはHugging Faceでの重み配布だけ。llama.cpp・MLX・ExecuTorchの最適化統合は「数日以内(in the coming days)」。Ollama・LM Studio・Unsloth、vLLM・SGLang、Together AI・Fireworks AI・OpenRouterも同じく「数日以内」です。
  • Metaは「プライバシー」とは言っていない。公式ブログの本文に privacy の語は出てきません。位置づけは「同サイズ帯の主要モデルと比べて強い性能」で、押しているのはネット接続の有無にかかわらずどこでも動くことです。
もう少し詳しく
技術面
上位モデル「Muse Spark」の出力からlogit蒸留(教師と近いデータ配合を使用)。公式ブログにバージョン番号の記載はありません。フル精度なら55GB超のところを4bit相当まで量子化して20GB未満にし、画像理解用のperception encoderと投機的デコーディング用のdrafterを同時に載せても24GB / 32GBに収まるようにしています。
速さの工夫
DFlashベースの小さな「drafter」モデルを同梱し、トークンの塊をまとめて提案させて本体が並列に検証する投機的デコーディングを使います。出力品質は変わらないとMetaは書いています。速度計測はMacBook M4-Max / M5-Max と RTX 5090 上で、K-Quant-17GB版とdrafterの組み合わせで行われました。
入力はマルチモーダル
専用のperception encoderにより、テキストと画像を交互に入力できます。比較対象として挙げられているのは Gemma4-31B と Qwen3.6-27B です。

AIエージェント「Manus」がMetaから独立 — 一部の利用者は8月23日朝までにデータ退避が必要

8/11 ✓ 公式確認済 買収解消 エージェント

Manusは8月11日、独立企業としての運営に戻ると公式ブログで発表しました。この記事で唯一、読者が期限までに手を動かす必要がある項目です。対象になった利用者は、8月23日の朝までにデータをバックアップしないと消えます。

  • 消えるのは「一部の利用者が2025年12月29日以降に作ったデータ」。12月29日はMetaがManusを買収した日です。特定の地域の規制要件に従うため、その日以降に生成されたデータを削除するとManusは説明しています。全利用者が対象ではありません。
  • 公式の日程はシンガポール時間(SGT)。日本時間はその1時間後。SGTはUTC+8、JSTはUTC+9です。
  • 対象かどうかはアプリ内通知とメールで届く。Apple IDやFacebookアカウントで登録した人はManusがメールアドレスを持っていないため、アプリ内通知を見る必要があります。ヘルプセンターに判定用のガイドもあります。対象外の人は何もしなくて構いません。
  • バックアップ期間中は課金されない。8月11日〜23日(SGT)は対象利用者に請求せず、復元後に「welcome back bonus」を出すとしています。
