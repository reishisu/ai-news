Windows 11 24H2のサポート終了は2026年10月14日。25H2は自動で届く

Microsoftのライフサイクルページに載っている、バージョン24H2の終了日は2026年10月14日（太平洋時間）です。25H2は自動で配信され、受け取るための操作は要りません。

24H2は2026年10月14日まで 25H2は自動配信 確認は1か所だけ

3行で言うと

  1. Windows 11 バージョン24H2のサポート終了日は、2026年10月14日 6:59:59 AM（太平洋時間）です。日本時間では同じ日の22:59:59にあたります。
  2. 設定 → システム → バージョン情報を開いて「25H2」か「26H1」と出ていれば、何もしなくてかまいません。それぞれ2027年10月13日、2028年3月15日まで（太平洋時間）サポートされます。
  3. 24H2のままでも、25H2は自動で届きます。Microsoftは「受け取るために必要な操作はありません」と書いています。待ちたくないときだけ「更新プログラムのチェック」を押します。

124H2の終了日は2026年10月14日、日本時間では22:59:59

Microsoft Learnのライフサイクルページ「Windows 11 ホーム アンド プロ」に、バージョンごとの開始日と終了日が表で載っています。適用されるエディションは、Home、Pro、Pro Education、Pro for Workstations、SEです。

ページには「サポートの日付は、太平洋標準時ゾーン (PT) - Redmond、WA、USA で表示されます」と書かれています。表の日付はすべて現地時間です。

バージョン開始日（PT）終了日（PT）
26H12026/2/10 8:00:00 AM2028/3/15 6:59:59 AM
25H22025/9/30 8:00:00 AM2027/10/13 6:59:59 AM
24H22024/10/1 8:00:00 AM2026/10/14 6:59:59 AM
23H22023/10/312025/11/12（終了済み）
22H22022/9/202024/10/9（終了済み）

終了日の時刻はいずれも 6:59:59 AM です。24H2の 2026/10/14 6:59:59 AM（PT）は、日本時間では2026年10月14日22:59:59にあたります。

日本時間への換算のしかたを見る 10月14日は米国の夏時間の期間内なので、太平洋時間は協定世界時より7時間遅れます。6:59:59 − (−7時間) = 13:59:59 UTC。日本標準時は協定世界時より9時間進んでいるので、13:59:59 + 9時間 = 22:59:59（同日）。この換算は筆者が計算したもので、Microsoftのページには日本時間の記載はありません。

ページには注記もあります。「Windows 11バージョン 24H2 は、Windows 11 SE エディションでサポートされている最後のバージョンでした」と書かれています。

2「終了」は更新プログラムが届かなくなること

表の「終了日」が何を意味するのかは、同じMicrosoft Learnの「ライフサイクルに関する FAQ - Windows」に書かれています。原文はこうです。

ライフサイクルFAQ（日本語版）の原文
Microsoft オペレーティング システム (OS) がサポート終了になると、お客様は技術的なサポート、ソフトウェア更新プログラム、またはセキュリティ修正プログラムを受け取ることができなくなります。

同じFAQのWindows 11の項にも、受け取り続けるための条件が書かれています。

同FAQ「Windows 11 のバージョンのサービス タイムライン」より
新しいバージョンの Windows 11 は年に 1 回リリースされ、セキュリティとセキュリティ以外の更新プログラムを含む毎月の品質更新プログラムを受け取る予定です。 Microsoft によるサポートを継続するには、現在のバージョンがサービス終了になる前に、常に最新バージョンをインストールする必要があります。

つまり終了日を過ぎると、そのバージョンには毎月の品質更新プログラムとセキュリティ修正が届かなくなります。PCが動かなくなるのではなく、更新が止まります。

同じFAQには、Home、Pro、Pro Education、Pro for Workstations、SEのサービスタイムラインは「リリース日から 24 か月」と書かれています。そしてHome版には脚注が付いています。

同FAQ、サービスタイムライン表の脚注1
Home Edition は機能更新プログラムの延期をサポートしていないため、通常、表示されているサービス終了日より前に新しいバージョンの Windows 11 を受け取ります。

Microsoft自身が、Homeは終了日より前に新しいバージョンを受け取るのが通常だと書いています。次の節の「操作は要らない」という説明と同じ方向です。

325H2か26H1なら、何もしなくていい

Windows release healthの「Windows 11, version 25H2 known issues and notifications」には、配信の状況がこう書かれています。

Windows release health（25H2）の原文
Windows 11, version 25H2 is now available for all eligible devices. Devices running Home and Pro editions of Windows 11 that are not managed by IT departments will receive the update to Windows 11, version 25H2 through the machine learning-based intelligent rollout.

続けて、受け取るために何かをする必要はないと明記されています。

同ページ、配信のタイミングについて
Updates are delivered when devices are ready, helping keep devices running smoothly and securely while ensuring they stay up to date with the latest protections. You can choose when to restart or postpone the update, and no action is required to receive it.

条件は「対象の端末であること」と「IT部門が管理していないHome・Proであること」の2つです。この条件に当てはまるなら、25H2は待っていれば届きます。

自分のバージョンは、設定 → システム → バージョン情報の「Windows の仕様」で確認できます。筆者のPCで実際に開いた画面がこれです。

項目この画面での表示
エディションWindows 11 Pro
バージョン25H2
インストール日2024/12/21
OS ビルド26200.9168

見るのは「バージョン」の行だけです。ここが25H2か26H1なら、2027年10月13日または2028年3月15日（PT）まで、この記事でやることはありません。

424H2のままの人は、待つか「更新プログラムのチェック」を押す

バージョンが24H2でも、前の節のとおり25H2は自動で届きます。待ちたくない場合の手順は、同じページに書かれています。

Windows release health（25H2）、待ちたくない場合
If you have an eligible Windows 10 or Windows 11 device, and you don’t want to wait for the intelligent rollout, go to Settings > Windows Update and select Check for updates. If your device is ready for the update, you’ll see the option to Download and install Windows 11, version 25H2.

日本語版の画面では、設定 → Windows Update を開いて「更新プログラムのチェック」を押します。押した直後の画面がこれです。

押す前の画面はこうでした。筆者のPCは既に25H2なので、25H2への案内は出ていません。

この画面には「更新の一時停止」の項目があり、「日付を選択」から停止する期日を選べます。原文でも postpone the update ができると書かれています。いま再起動されると困る、という理由でなら止められます。

ただし止めたままにすると、24H2の終了日を過ぎたときに第2節の状態になります。止めるのは一時的な回避であって、終了日そのものは動きません。

5管理された端末・既知の問題・要件を満たさないPC

3つ、注意点があります。

  • 会社や学校が管理するPCは、管理者が決めます。原文の自動配信は「not managed by IT departments」の端末に限った説明です。管理下の端末は情報システム部門の指示に従ってください。
  • 既知の問題は、25H2に固有のものではありません。後述の2件は、25H2のページにも24H2のページにも同じように載っています。
  • Windows 11の要件を満たさないPCに25H2を入れる方法は、この記事では扱いません。一般の利用者に勧められる手順ではないためです。

既知の問題は、2026年9月3日に取得した時点で次の2件が両方のページに載っていました。詳細はリンク先で確認してください。

症状originating update状態
ARM機でTeamsと新しいOutlookが起動しないことがあるKB5121003（2026-08-11）Mitigated
英語以外のWindowsでマウスのカスタマイズが元に戻るKB5120998（2026-08-27）Confirmed

どちらも25H2に上げたから起きるものではありません。25H2を避ける理由にはならない、というのがこの2件の位置づけです。

6やっていないこと

この記事で確かめていないことを、そのまま書きます。

  • 24H2のPCに25H2が自動で届く瞬間は撮っていません。筆者のPCは既に25H2のためです。自動配信の説明は、Windows release healthの原文だけを根拠にしています。
  • 要件を満たさないPCへの25H2の導入は、試していません。扱わないと決めた範囲です。
  • 管理された端末での挙動は確認していません。Intuneやドメイン参加の環境は手元にありません。
  • Windows 10については書いていません。この記事はWindows 11 24H2の終了日だけを扱います。
  • 既知の問題2件は、自分では再現していません。ページの記載を照合しただけです。
