# 2026-08-14_ai-basics の検証環境

記事「AIにコードを任せるまでの4段階 — プロンプトからループまで」に
貼ったターミナル出力を、そのまま再現するための一式です。

## 何を確かめたか

1. わざと `>` と `>=` を間違えた `shipping.py` に対して pytest が何を出すか
2. その pytest を Claude Code のフック(`.claude/hooks/pytest.sh`)から叩いたときの終了コード
3. 「テストが通るまで直させる」ループ(`loop.sh`)が、実際に2周で止まること
4. ループを `| tail -1` に繋ぐと、**落ちているのに成功扱いになる**こと(`loop_broken.sh`)

## 動かし方

```bash
./run_all.sh > output.txt 2>&1   # 記事の4ブロック分をまとめて取り直す
python3 verify_pasted.py          # 記事に貼った出力が output.txt に実在するか照合
```

`run_all.sh` は毎回 `shipping.py` のバグを入れ直してから走るので、何度実行しても同じ結果になります。

## 出力の幅について（重要）

CLAUDE.md 第4節で「1行は半角40桁まで」と決めているため、**`export COLUMNS=40` を付けて実行しています。**
pytest はこの環境変数を見てセパレータ行(`=== FAILURES ===` など)と進捗行(`[100%]`)の幅を詰めます。

- **40未満を指定しても効きません。** pytest は下限を持っていて、80桁に戻ります(26/30/34 で実測)
- **日本語のテスト名だと、それでも40桁を超えます。** pytest は幅を「文字数」で数えるので、
  全角文字が表示上2桁ぶん占めることを考慮しません。
  `_________ test_ちょうど3000円は送料無料 __________` は40文字ちょうどですが、表示幅は50桁です
- 記事に残っている40桁超えは7行で、最長54桁です(素の実行では16行・最長90桁でした)

`loop.sh` は `pytest -q --tb=no` を使っています。ループのたびにトレースバックを全部出すと
読めないためで、記事に載せているコードも同じです。
