`orders.py` に、レビューで指摘したい欠陥を14件仕込んである。
「機械が捕まえる」ことを期待して入れたのが9件、「人が読まないと分からない」
つもりで入れたのが5件。実行結果は `output.txt`。

| D03 | 62 | bare except | ruff E722 |
| D04 | 32 | 可変デフォルト引数 `seen={}` | ruff B006 |
| D05 | 71 | プレースホルダの無い f-string | ruff F541 |
| D06 | 64 | 使っていないローカル変数 `receipt` | ruff F841 |
| D07 | 72 | str を int の引数に渡した | mypy arg-type |
| D08 | 29,37 | Optional を None チェックせず添字 | mypy index |
| D09 | 78 | list を int として返した | mypy return-value |
| D10 | 27-30 | **他人の注文を返せる**(権限チェック無し) | どれも捕まえず |
| D11 | 35,37 | **ループの中でDBを引く**(N+1) | 自作 HR01 |
| D12 | 43-45 | **境界が仕様と逆**(3000円ちょうどが有料) | どれも捕まえず |

  どちらも仕様側にしか答えがない
