================================
(config/cors.php は置いていない)

-- 1a. それでも設定は存在する
$ php artisan config:show cors

 paths ⇁ 0 .. api/* 
 paths ⇁ 1 .. sanctum/csrf-cookie 
 allowed_methods ⇁ 0 .. * 
 allowed_origins ⇁ 0 .. * 
 allowed_origins_patterns .. [] 
 allowed_headers ⇁ 0 .. * 
 exposed_headers .. [] 
 max_age .. 0

-- 1b. api/* のGETに Origin を付ける
$ curl -s -o /dev/null -D - \
 -H "Origin: $OK_ORIGIN" \
 "$API"
HTTP/1.1 200 OK
Access-Control-Allow-Origin: *


-- 1c. api/ で始まらないパスに同じことを
$ curl -s -o /dev/null -D - \
 -H "Origin: $OK_ORIGIN" \
 "$WEB"
HTTP/1.1 200 OK


-- 1d. Origin を付けない
$ curl -s -o /dev/null -D - "$API"
HTTP/1.1 200 OK
Access-Control-Allow-Origin: *
