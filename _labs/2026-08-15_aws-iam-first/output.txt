11. 判定順のおもちゃ実装
======================================
要求 s3:GetObject
対象 logs/report.csv
--------------------------------------
何も付けない
  -> Deny : 暗黙のDeny(許可が無い)
読取Allowだけ
  -> Allow : 許可あり・拒否なし
Allow+Deny
  -> Deny : 明示的なDeny
境界:s3:Get*
  -> Allow : 許可あり・拒否なし
境界:dynamodbのみ
  -> Deny : 境界が許可していない
MFA必須/MFAなし
  -> Deny : 暗黙のDeny(許可が無い)
MFA必須/MFAあり
  -> Allow : 許可あり・拒否なし
