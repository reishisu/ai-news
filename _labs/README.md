# _labs — 記事の検証物

記事のために書いた検証コード・テスト・実行結果・図の元データを、記事ごとに置きます。
`_` 始まりなので GitHub Pages には公開されませんが、Gitで追跡されます。

## 置くもの

- 検証コード・テストコード（記事に貼ったものと同一）
- 実行結果（`output.txt` など。記事の記述と突き合わせられるように）
- フローチャート・シーケンス図・クラス図（Mermaid記法の `.md` でよい）
- `README.md`（何を確かめたか / 動かし方 / 実行時の環境とバージョン）

## なぜ残すか

記事を直すとき、**前回と同じ条件で測り直せる**ようにするためです。
数値を書き換えるときは、記憶や推測ではなく、ここで実際に測り直してください。
